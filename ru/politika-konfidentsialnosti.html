Политика конфиденциальности сайта

Черновик — не публиковать без юридической вычитки Этот документ подготовлен как рабочий черновик для запуска первой версии сайта и пока не проверен юристом. Перед публичным запуском его нужно показать юристу (желательно — практикующему в Парагвае и знакомому с применимым к сайту правом), а также заменить тестовые реквизиты компании на реальные.

Этот документ описывает обработку данных посетителей и пользователей самого сайта grundparaguay.com — куки, формы, аналитика. Это не то же самое, что клиентское соглашение о конфиденциальности, которое защищает данные иммиграционного дела уже подписавших соглашение клиентов, — оба документа нужны и решают разные задачи (см. пояснение на странице «Конфиденциальность»).

1. Какие данные мы собираем

1.1. Данные, которые вы указываете сами: имя, контакт для связи (Telegram, email, телефон), текст сообщения — при заполнении формы заявки на странице «Контакты».

1.2. Технические данные о посещении сайта: обезличенные данные веб-аналитики (страницы, длительность визита, источник перехода) — при условии, что аналитика подключена (см. пункт 4).

1.3. Файлы cookie — небольшие технические файлы, которые сайт может сохранять в браузере для базовой работы сайта и аналитики.

2. Для чего используются данные

2.1. Данные формы заявки используются исключительно для связи с вами по поводу консультации и оказания услуг.

2.2. Данные аналитики используются для понимания того, какие страницы сайта востребованы, и для улучшения содержания сайта.

2.3. Мы не используем ваши данные для целей, не связанных с обработкой заявки или улучшением сайта, и не продаём их третьим лицам.

4. Передача данных третьим лицам

4.1. Мы не передаём данные, собранные через сайт, третьим лицам, за исключением сервисов, технически необходимых для работы сайта (хостинг, сервис аналитики, сервис приёма формы/CRM) — и только в объёме, необходимом для их работы.

5. Ваши права

5.1. Вы можете запросить удаление ваших данных, переданных через форму на сайте, написав на office@fortuna-vida.com.py или в Telegram @grundparaguay.

6. Изменения политики

6.1. Мы можем обновлять этот документ по мере развития сайта; актуальная версия всегда доступна по этому адресу.

7. Контакты

По вопросам обработки данных сайта — office@fortuna-vida.com.py.
